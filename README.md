# RP Skibidi Prototypes

RP Skibidi Prototypes is a Minecraft plugin designed to enhance roleplaying experiences in Minecraft servers. It provides a set of commands and features to facilitate roleplaying activities, including character creation, dialogue, and scenario management. The plugin is built with a focus on simplicity and flexibility, allowing server administrators to customize the roleplaying experience to their players' needs.

## Install

1. Download the plugin JAR file from the [releases page](https://github.com/EnderDevelopment/RPSkibidiPrototypes/releases).
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart or reload your Minecraft server to load the plugin.

## Use

1. **Basic Command**: Use the `/rp` command to access the main roleplaying menu.
2. **Character Creation**: Create and manage your roleplaying characters using the plugin's character creation system.
3. **Dialogue**: Engage in roleplaying conversations with other players using the dialogue system.
4. **Scenario Management**: Create and manage roleplaying scenarios to provide structured roleplaying experiences.
